# 📊 Traffic Accidents in Colombia (1970–2025)


## 📌 Project Overview

This repository contains an exploratory and analytical study of traffic accidents in Colombia between **1970 and 2025**.

The dataset was obtained from the official Colombian open data platform:
👉 https://www.datos.gov.co/

The objective of this project is to identify long-term trends, regional patterns, and relevant statistical behaviors in accident data to support data-driven insights and policy evaluation.

---

## 🧠 Methodology

1. **Data Collection**  
   Public datasets were extracted from the Colombian Open Data portal (datos.gov.co).

2. **Data Cleaning & Preprocessing**  
   - Handling missing values  
   - Standardizing formats  
   - Filtering inconsistent records  
   - Structuring time-series data  

3. **Exploratory Data Analysis (EDA)**  
   - Yearly trend analysis  
   - Regional distribution analysis  
   - Accident severity patterns  
   - Comparative historical analysis  

4. **Visualization**  
   Graphical representations were generated to highlight temporal evolution and structural patterns in the dataset.

---

## 📈 Key Objectives

- Understand the historical evolution of traffic accidents in Colombia  
- Identify high-risk periods or regions  
- Detect long-term patterns and anomalies  
- Provide structured datasets for further modeling or predictive analysis
